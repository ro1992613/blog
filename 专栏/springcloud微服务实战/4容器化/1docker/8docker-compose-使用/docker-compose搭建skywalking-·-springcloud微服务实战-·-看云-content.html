在前面我们已经说明了Skywalking的基本使用以及在Windows的快速安装使用，下面我们来演示使用docker的方式部署Skywalking。

数据存储我们选择性能更高的Elasticsearch，虽然我们之前在搭建ELK的时候已经部署过了Elasticsearch，但必须在之前的基础上添加一些Elasticsearch配置，否则会出现collector无法访问Elasticsearch的情况，本节将重新搭建一个Elasticsearch数据库

1. 创建Elasticsearch的挂载目录和配置文件

1.1 创建Elasticsearch的挂载目录

mkdir -p /fwcloud/elasticsearch/data /fwcloud/elasticsearch/logs

1.2 创建Elasticsearch的配置文件elasticsearch.yml

vim /fwcloud/elasticsearch/elasticsearch.yml

1.3 配置文件elasticsearch.yml

network.host，network.host 要配置成 skywalking 可以访问得到的地址，这里配置了0.0.0.0

http.host: 0.0.0.0
http.cors.enabled: true
http.cors.allow-origin: "*"
transport.host: 0.0.0.0

1.4 授予最高权限

chmod 777 -R /fwcloud/elasticsearch

2. 创建 Skywalking 的挂载目录和配置文件

2.1 创建skywalking-oap的挂载目录

mkdir -p /fwcloud/skywalking/config

2.2 创建skywalking-oap的配置文件application.yml

touch /fwcloud/skywalking/config/application.yml

2.3 配置文件application.yml

3. 完整docker-compose.yml配置

在config 目录添加docker-compose.yml

touch /fwcloud/skywalking/config/docker-compose.yml

添加下面内容

version: '3'

services:
  elasticsearch:
    image: elasticsearch:6.5.4
    container_name: elasticsearch
    restart: always
    environment:
      - cluster.name=elasticsearch
      - xpack.security.enabled=false #关闭x-pack安全认证
      - "ES_JAVA_OPTS=-Xms512m -Xmx512m" #jvm内存分配为 512MB
      - "discovery.type=single-node" #单节点启动
      - "TZ=Asia/Shanghai"
    volumes:
      - /fwcloud/elasticsearch/data:/usr/share/elasticsearch/data
      - /fwcloud/elasticsearch/logs:/usr/share/elasticsearch/logs
      - /fwcloud/elasticsearch/elasticsearch.yml:/usr/share/elasticsearch/config/elasticsearch.yml
    ports:
      - 9200:9200

  skywalking-oap:
    image: apache/skywalking-oap-server:6.5.0
    container_name: skywalking-oap
    depends_on:
      - elasticsearch
    links:
      - elasticsearch
    restart: always
    ports:
      - 11800:11800
      - 12800:12800
    environment:
      - "TZ=Asia/Shanghai"
    volumes:
      - /fwcloud/skywalking/config:/apache-skywalking-apm-bin/config:ro

  skywalking-ui:
    image: apache/skywalking-ui:6.5.0
    container_name: skywalking-ui
    depends_on:
      - skywalking-oap
    links:
      - skywalking-oap
    restart: always
    ports:
      - 8080:8080
    environment:
      - "collector.ribbon.listOfServers=skywalking-oap:12800"
      - "TZ=Asia/Shanghai"

4. 与SpringCloud 的整合

前面在说Skywalking已经演示操作过程，现在只需要安装之前的步骤替换一下连接地址即可。

注意

docker-compose.yml中我们通过TZ=Asia/Shanghai设置了时区，如果不指定时区的话默认是UTC时区，你会看到收集到的数据会比实际早8个小时。

在启动之前我们还需要通过sysctl -w vm.max_map_count=262144命令设置内存权限，262144是构建Elasticsearch的最小内存。
